# .github

Organization-wide files for [pelagolang](https://github.com/pelagolang).

- `profile/README.md` is the public organization page.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` and `SUPPORT.md` are the defaults every repository in the organization shows unless it has its own.
- `.github/ISSUE_TEMPLATE/` and `.github/pull_request_template.md` are the default issue forms and pull request template. The `pelago` repository keeps its own, more detailed pull request template.

The member-only page lives in [`.github-private`](https://github.com/pelagolang/.github-private).
