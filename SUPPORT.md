# Getting help

- **Using Pelago.** Read the [README](https://github.com/pelagolang/pelago#readme), the [syntax tour](https://github.com/pelagolang/pelago/blob/main/examples/tour.pel) and the design docs under [`docs/design/`](https://github.com/pelagolang/pelago/tree/main/docs/design). The [examples](https://github.com/pelagolang/examples) repository has runnable programs.
- **Something is broken.** Open a bug report in the repository it concerns (compiler and language server: [pelago](https://github.com/pelagolang/pelago); editor support: the extension's repository). A minimal `.pel` file and the output of `pelago --version` help most.
- **An idea.** Open a feature request. For language changes, say what problem it solves before the syntax.
- **A security problem.** Do not use issues; see [SECURITY](SECURITY.md).
